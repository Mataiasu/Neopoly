Addon - Pack Manager

GESTIONNAIRE D'ADDONS UI

Ce pack manager active/desactive des addons directement depuis une fenetre dans le jeu, sans modifier manuellement le script principal.

Etape 1 : Ajoute une seule ligne dans test1.html (juste avant body).
<script src="assets/addon-pack-manager.js"></script>
Etape 2 : Lance la partie puis clique sur le bouton Addons en bas a droite.

Addons geres actuellement par le manager: Saisons Dynamiques, Prets Bancaires, Optimisation Rendu, Encheres, Evenements Aleatoires et Mode Blitz. Les choix sont sauvegardes automatiquement dans le navigateur (localStorage).

Compatibilite : Le manager applique des patches conditionnels; desactiver un addon stoppe son effet sans casser la partie en cours.
